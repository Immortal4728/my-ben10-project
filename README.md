Interactive UI Showcase (React)

A smooth, animation-focused frontend project built with React and Vite.
The goal of this project is simple: clean UI flow, responsive layouts, and subtle motion that feels intentional — not noisy.

This project is deployed on GitHub Pages and was built to strengthen frontend fundamentals like component structure, asset handling, and performance-aware animations.

Live demo
https://immortal4728.github.io/Ben10/

What this project does
• Uses Vite + React for fast builds and a clean development experience ⚡
• Interactive carousel with smooth, controlled transitions 🎞️
• Responsive layout that adapts across devices 📱💻
• Motion-based animations for better visual flow 🧠
• Proper static asset handling for production deployment 🌐

Tech used
• Frontend: React, Vite, JavaScript
• Styling: CSS
• Animations: Framer Motion
• Icons: React Icons
• Deployment: GitHub Pages

Project structure

src/
├── components/   🧩 reusable UI components
├── pages/        📄 page-level views
├── assets/       🖼️ images and static files
├── styles/       🎨 global and component styles
└── main.jsx      ⚡ application entry point


What I learned
• Structuring a React project cleanly
• Managing animations without hurting performance
• Handling asset paths correctly for static hosting
• Deploying and maintaining frontend projects
• Writing UI code that’s readable and scalable

Notes
This is a frontend-focused project.
No backend here — just UI, structure, and polish.
Built as a foundation before moving into full-stack applications.
